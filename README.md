## 🧠 Current Focus: Agentic Quality Engineering

I am exploring how **AI agents can transform traditional software testing** from script-driven automation into intelligent, goal-driven quality engineering.

### AgenticPlaywright

My current exploration focuses on building AI-powered agents that can:

```text
Requirement
     ↓
AI Agent
     ↓
Application Exploration
     ↓
Test Scenario Generation
     ↓
Playwright Test Generation
     ↓
Test Execution
     ↓
Failure Analysis
     ↓
Intelligent Recommendations
```

The goal is to move from:

> **"Write automation scripts for the application"**

towards:

> **"Give an AI agent a testing objective and let it reason, explore, generate, execute, and analyze tests."**

## ⚡ Performance Engineering

I design performance tests around **realistic user behavior and business workload models**, rather than simply generating a large number of HTTP requests.

Recent work includes:

* k6-based single-user journey modeling
* VOD and live-stream workload modeling
* Multi-persona traffic distribution
* Distributed k6 execution using Kubernetes
* Large-scale concurrent-user simulation
* Performance test phases: smoke, load, stress, spike, and endurance
* Grafana-based performance monitoring and analysis

## 📈 Quality Engineering Philosophy

I believe modern QA should evolve from:

```text
Manual Testing
      ↓
Test Automation
      ↓
Continuous Testing
      ↓
Quality Engineering
      ↓
AI-Assisted Testing
      ↓
Agentic Quality Engineering
```

The objective is not simply to **increase the number of automated tests**.

The objective is to build systems that continuously help teams:

**Prevent defects → detect risks earlier → automate intelligently → understand failures → deliver faster with confidence.**
